# Power BI / Business Intelligence Dashboards

This directory contains resources for executive business intelligence reporting:

- `dax_measures.md`: Documented DAX measures for Churn %, MRR at Risk, Customer Lifetime Value (CLV), and Retention Rates.
- `data_model_design.md`: Star schema / snowflake relational data model diagrams and table relationships.
- Dashboard templates and exported PBID/PBIX assets.
